# 会話で守る文章の要点

yomiyasu（`yomiyasu:yomiyasu`）の基本原則のうち、会話の返答でも守れるものだけを抜き出した。
ドキュメントや PR の概要など残る文章は、ここで済ませず yomiyasu 本体で推敲する。

- 意味を変えない。主張・比重・言い切りの強さを、元の根拠どおりに保つ。
- 情報を足さない。元に無い担当者・理由・効果を補わない。分からないことは分からないと書く。
- 主語と目的語を書く。「誰が・何を」が文脈から取れないときは省かない。
- 擬人化と比喩動詞を避ける。「コードが叫ぶ」「データが壊れる」ではなく、起きることをそのまま書く。
- 中身の無い予告文を書かない。「以下で詳しく説明します」は書かず、説明から入る。
- 自分の文章にラベルを貼らない。「重要なポイントです」「ここが肝です」と言わず、内容で示す。
- 大げさな名詞を使わない。「抜本的な」「堅牢な設計を実現」のように、中身より大きい言葉を避ける。
- 装飾記号を使わない。絵文字、文末の飾りのコロン、ダッシュ記号でつながない。
- 太字は表示される書き方にし、多用しない。
- 箇条書きは、並列関係がはっきりしたものに限る。理由や因果のつながりは地の文で書く。
